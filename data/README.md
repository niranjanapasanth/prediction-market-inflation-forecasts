# Data

This directory contains processed research datasets used by the notebooks.

- `fixed_horizon_snapshots.csv`: contract observations standardized to fixed pre-release horizons.
- `forecast_panel_adjusted.csv`: monotonicity-adjusted survival probabilities by threshold.
- `forecast_panel_summary.csv`: event/horizon forecast summaries.

Raw Kalshi API responses are intentionally omitted. The notebooks document how the raw data were acquired and transformed. Do not add API keys, credentials, or local raw-data folders to the repository.
